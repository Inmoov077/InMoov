Wiring & Diagnostics

If servos do not respond, verify:

  1. Signal Cables: Pin 3 → Neck, Pin 4 → Eye, Pin 5 → Jaw.
  2. Shared GND: External PSU ground must link to Arduino GND.
  3. External Power: Use dedicated 5V–6V PSU for servos.
  4. Baud Rate: Confirm Arduino sketch is set to 9600.
  5. Neck Pins: Pin 6 → Rotation, Pin 7 → Tilt, Pin 8 → Roll.
